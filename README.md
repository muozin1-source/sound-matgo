# 소리 맞고

아이폰 Safari와 VoiceOver를 중심으로 만든 **사람 대 컴퓨터 1대1 맞고**입니다. 손패를 아래쪽에 고정하고, 내고 가져오는 과정을 짧은 안내와 효과음으로 표현합니다. 로그인, 서버, API 키, 결제, 데이터베이스가 필요 없습니다.

## 실행

일반 사용자는 GitHub Pages 주소를 Safari에서 열면 됩니다. 별도 설치나 npm 설치·빌드가 필요하지 않습니다. JavaScript 모듈을 사용하므로 PC에서 `index.html`을 파일로 직접 더블클릭하는 대신 HTTP 서버 또는 Pages를 사용하세요.

Node.js가 있는 PC에서 미리 실행하려면 이 폴더에서:

```sh
node preview.cjs
```

표시된 `http://127.0.0.1:4184/`를 같은 PC의 브라우저로 엽니다. 이 주소는 아이폰 접속용이 아닙니다.

## 플레이

1. ‘게임 시작’ 또는 ‘이어하기’를 실행합니다. 이 동작으로 iPhone의 오디오 재생도 시작합니다.
2. **화면 아래 손패**에서 낼 패를 찾고 두 번 탭합니다. VoiceOver로 훑는 것만으로는 내지 않습니다. 별도 확인창 없이 바로 냅니다.
3. 같은 월의 바닥패가 두 장이면 가져올 패를 고릅니다. 뒤집은 패에서도 선택이 필요하면 이어서 고릅니다. 낼 패를 이미 정했으므로 이 선택은 취소할 수 없습니다.
4. 차례 결과를 짧게 알리고, 상대가 자동으로 플레이합니다. 내 차례가 되면 남아 있는 손패로 초점이 돌아옵니다.
5. 7점 이상에서 ‘고!’ 또는 ‘스톱!’을 선택합니다. 고 이후에는 획득 점수가 올라야 다시 선택합니다.

손패는 처음 월순으로 2줄에 배치하며, 낸 자리는 빈 공간으로 남겨 다른 패 위치를 보존합니다. 보너스패를 내고 받은 새 패는 같은 자리에 배치합니다. 폭탄 등으로 여러 장을 낸 자리도 비워 둡니다.

바닥패는 1~12월의 고정 버튼입니다. 해당 월을 실행해 종류와 수량을 확인할 수 있습니다. ‘내 현황’과 ‘상대 현황’에는 점수 조합, 획득 패, 고 횟수와 미션이 있습니다. 상대 손패의 내용과 뒤집기 전 더미는 화면 읽기에도 노출하지 않습니다.

‘특수’에서 흔들기, 폭탄, 폭탄으로 비운 차례의 뒤집기를 선택합니다. 국진을 처음 얻으면 열끗/쌍피를 고르며, 내 차례의 ‘내 현황’에서도 바꿀 수 있습니다.

## 규칙과 구현 범위

`itsent-lab/hwatu`의 MIT 맞고 엔진을 고정 리비전에서 가져와 사용합니다. 광·고도리·띠·피, 고·스톱, 뻑·쪽·따닥·싹쓸이, 흔들기·폭탄, 총통, 박, 각패 미션, 나가리 이월을 처리합니다. **우리 게임의 정확한 규칙과 원본과의 차이는 [RULES.md](RULES.md)**에 있습니다.

화면과 VoiceOver 조작은 새로 작성했습니다. 3인 고스톱, 온라인 사람 간 대전, 계정, 서버 저장은 포함하지 않습니다. 정산은 점수로 표시합니다.


## 접근성·검증

일반 글자 크기의 402×652 및 320×640 CSS px를 목표로 합니다. 글자 확대·가로 방향·낮은 화면에서는 조작이 잘리지 않도록 스크롤을 허용합니다. 확대를 금지하지 않습니다. 화면 읽기 이름, 상태 메시지, 네이티브 버튼·대화상자, 키보드 Tab/Enter/Space와 Escape를 사용합니다. 필수 게임 선택은 Escape로 취소할 수 없습니다.

검증 기록은 [VERIFICATION.md](VERIFICATION.md)에서 확인하세요. **실제 아이폰·VoiceOver 사용자 검증 및 플레이 시간 실측은 별도로 필요합니다.**

## 개발

Node.js 24 이상에서, 별도 패키지 설치 없이:

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
```

`vendor/engine`의 TypeScript를 Node 내장 타입 제거 기능으로 `engine`의 브라우저 JavaScript로 변환합니다. 생성된 `engine`도 함께 배포하므로 플레이어는 빌드할 필요가 없습니다. 원본 테스트는 참고용 `vendor/tests`에, 이 게임의 실행 가능한 검증은 `tests`에 있습니다.
